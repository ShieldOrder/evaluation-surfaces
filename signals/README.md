# Signals

These documents describe legitimacy and evaluation signals, and where they are credible.

A signal is an observable input people use to judge a decision, such as expertise, turnout, economic exposure, deliberation process, or execution outcomes.

Signals are frequently misapplied. The point here is to name:
- what a signal can credibly evaluate
- what it cannot credibly evaluate
- what failure modes appear when it is overextended
