# Decision Surfaces

These documents define decision surface types. A decision surface is the object being decided, plus the constraints that make some evaluation signals relevant and others irrelevant.

These definitions are descriptive and non-prescriptive.

Use:
- pick the closest surface type for the decision under discussion
- then evaluate which signals can credibly speak to that surface

Files in this directory should:
- state what the surface is
- state what is in scope for that surface
- list signals that are typically relevant
- list signals that are typically not credible for that surface
