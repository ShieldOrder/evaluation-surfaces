# Failure Modes

These documents describe common pathologies that arise when legitimacy signals
are applied outside their credible domain.

The goal is not to accuse. The goal is to reduce confusion by naming repeatable
error patterns that appear across governance contexts.

Each failure mode document should:

- describe the mismatch between signal and decision surface
- describe what breaks and how the failure manifests
- list typical symptoms and secondary effects
- describe neutral remediation options (language fixes, reframing, improved artifacts)
