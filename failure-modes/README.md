# Failure Modes

These documents describe common pathologies when signals are applied outside their credible domain.

The goal is not to accuse. The goal is to reduce confusion by naming repeatable error patterns.

Each failure mode document should:
- describe the mismatch (signal vs surface)
- describe what breaks and how it shows up
- list typical symptoms and secondary effects
- suggest neutral remediation options (language fixes, reframing, better artifacts)
