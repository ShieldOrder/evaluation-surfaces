# Contributing

This repository is analytical infrastructure.

Contributions are accepted when they increase:
- definitional clarity
- surface and signal coverage
- failure-mode precision
- neutrality and scope discipline

Preferred contributions:
- additions that are strictly descriptive
- wording changes that reduce implied advocacy
- examples that illustrate a category error without naming current disputes
- corrections to taxonomy or mappings

Out of scope:
- mechanism design proposals
- calls to adopt, reject, or prioritize a governance system
- arguments for specific reforms or actors
- protocol upgrade advocacy

Process:
- open an issue describing the change and its motivation
- submit a PR with minimal diffs and an explicit rationale
- include a short “scope check” note in the PR description
