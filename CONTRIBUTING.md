# Contributing

Posture:
- descriptive, non-prescriptive
- no advocacy or endorsements
- no authority claims

Contributions welcome:
- clarifications that reduce ambiguity
- new surface, signal, or failure mode documents with tight definitions
- examples that illustrate category errors without targeting individuals

Avoid:
- normative mandates
- calls for reforms
- accusations or personalized claims

If in doubt, open an issue first describing the proposed addition and the category it belongs to (surface, signal, failure mode).
